Topic 1

What is C?

✅ Complete

Compile and run this first — see what happens.

C is a compiled, general-purpose programming language created in 1972. You write source code in a .c file, a compiler translates it into machine instructions, and the machine runs those instructions directly.

That compilation step is what makes C programs extremely fast — the computer runs native instructions, not interpreted code. It also means mistakes are caught before the program runs, not during.

The program you just ran is a complete C program. Every piece of it has a specific job — you will understand each line by the end of this chapter.

The Compile → Run Cycle
Write code (.c file) → Compiler translates → Program runs main.c → gcc / clang → ./a.out
💡
Remember
C does not run line by line like Python. The compiler reads the entire file, checks everything, and either produces a runnable program or gives you a list of errors to fix.
🌍 Where C is used right now

The Linux kernel, Python's interpreter, MySQL, and the firmware in your keyboard are all written in C. When performance is critical and control over hardware is required, C is the language of choice.

/* From the Linux kernel — real C code, 2024 */
static int process_packet(struct sk_buff *skb)
{
    if (!skb || skb->len < ETH_HLEN)
        return -EINVAL;
    return forward_to_bridge(skb);
}

Topic 2

How C Works — The Compile Cycle

✅ Complete

This code has a deliberate error. Run it. Read what the compiler says.

The C compiler reads your entire source file, checks every line for mistakes, and refuses to produce a program if anything is wrong. This is different from languages that run line by line and crash mid-execution.

A compiler error is not failure — it is the compiler doing its job. The error message tells you exactly which line the problem is on and what is wrong. Read the error. Fix the line. Run again. That cycle is how every C programmer works.

Warnings are different from errors. A warning compiles but flags a potential problem — you should still fix them.

The Compile → Error → Fix Cycle
1. Write code 2. Compiler finds an error → tells you: file, line, what's wrong 3. Fix the line the error points to 4. Compile again 5. Either: more errors to fix, or program runs ✓
⚠
Common Mistake
Beginners read the first error, panic, and start changing random things. Read the error message. It tells you the line number. Go to that line. Fix that specific thing.
🌍 Real-world practice

Professional C developers compile code dozens of times per hour. The feedback loop — compile, read error, fix, compile — becomes second nature. The platform gives you that same loop in every exercise.

/* Terminal output after a compile error */
main.c:4:5: error: expected ';' before 'return'
    printf("Hello\n")
    ^
Fix: add ; after the printf line.

Topic 3

Understanding #include, main(), return 0

✅ Complete

Run this. Every line does something specific — observe the output first.

#include <stdio.h> tells the compiler to include the Standard Input/Output library. Without it, printf() doesn't exist — you'd get a compile error. Think of it as importing a toolbox before using the tools.

int main() is the entry point of every C program. Execution always starts here, no matter what else is in the file.

return 0; signals to the operating system that the program finished successfully. A non-zero return value conventionally means an error occurred.

Every C Program — Line by Line
#include <stdio.h> ← import the stdio library (gives you printf, scanf) int main() { ← entry point — execution starts here ← your code goes inside the braces return 0; ← tell the OS: "program finished cleanly" }
↔
Difference — #include vs import
Python uses import. C uses #include. Both bring in external functionality, but #include is processed by the preprocessor before compilation even begins — it literally pastes the header file contents into your code.
🌍 Multiple headers in a real program

Real C programs often include several headers. Each one unlocks a set of functions:

#include <stdio.h>    /* printf, scanf, fopen, fclose */
#include <stdlib.h>   /* malloc, free, rand, exit */
#include <string.h>   /* strlen, strcpy, strcmp */
#include <math.h>     /* sqrt, pow, sin, cos */

int main() {
    /* now all those functions are available */
    return 0;
}
