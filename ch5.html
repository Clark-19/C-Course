Operators

Operators are the symbols that perform actions on values. Every calculation, every comparison, every assignment in C uses operators. This chapter covers the ones you will use in every program you write.

Topic 1

Arithmetic Operators — + - * / %

✅ Complete

Compile and run this — five operators, five results. Look at line 5 (division) and line 6 (modulo) closely.

C has five arithmetic operators: + (add), - (subtract), * (multiply), / (divide), % (modulo — remainder).

Integer division truncates: 10 / 3 gives 3, not 3.33. The decimal part is dropped. This is one of the most common sources of bugs in beginner C programs.

The modulo operator (%) gives the remainder: 10 % 3 gives 1 because 10 ÷ 3 = 3 remainder 1. Modulo only works with integers.

Arithmetic Operators
int a = 10, b = 3; a + b → 13 // addition a - b → 7 // subtraction a * b → 30 // multiplication a / b → 3 // integer division (truncates!) a % b → 1 // modulo: remainder of 10 ÷ 3
⚠
Integer Division Drops the Decimal
int result = 7 / 2; → result is 3, not 3.5. If you need the decimal, at least one operand must be a float: 7.0 / 2 or (float)7 / 2.
🌍 Modulo in real programs

Modulo is used for wrapping (keep a value within a range), even/odd checks, and cycle detection — essential in games, clocks, and data processing.

/* Is this number even or odd? */
if (number % 2 == 0) printf("even\n");
else                  printf("odd\n");

/* Wrap angle: 365 % 360 = 5 degrees */
angle = (angle + degrees) % 360;

Topic 2

Integer Division vs Float Division — A Critical Distinction

✅ Complete

Run this — the same numbers, divided three different ways. All three produce different results.

When both operands are integers, C performs integer division — no decimal, truncated toward zero. To get a float result, at least one operand must be a float or double.

Three ways to force float division: use a float variable, use a literal decimal (7.0 instead of 7), or cast with (float) or (double).

Division — Three Patterns
int a = 7, b = 2; int result1 = a / b; // 3 — integer division float result2 = a / b; // 3.0 — still integer division! float result3 = (float)a / b; // 3.5 — cast forces float division float result4 = 7.0 / 2; // 3.5 — literal forces float division
⚠
float result = a / b still does integer division!
The type of the result variable does not change how the division is calculated. The calculation happens first (integer ÷ integer = integer), then it gets stored as float. You get 3.0, not 3.5.
🌍 The classic average bug

The most common beginner bug in C is computing averages with integer division. Always cast when you need a decimal result.

int total = 85 + 92 + 78;  /* = 255 */
int count = 3;

/* BUG: integer division gives 85, not 85.0 */
float avg_wrong = total / count;

/* CORRECT: cast one operand to float first */
float avg_right = (float)total / count;  /* 85.0 */

Topic 3

Assignment Operators — = += -= *= /= %=

✅ Complete

Run this — the shorthand operators modify a variable in place. Predict each value before running.

Compound assignment operators combine arithmetic with assignment in one step. x += 5 means exactly the same as x = x + 5 — it adds 5 to x and stores the result back in x.

They work for all five arithmetic operators: +=, -=, *=, /=, %=. They are shorter, clearer, and are used constantly in real C code.

Compound Assignment
int x = 10; x += 5; // x = x + 5 → x is now 15 x -= 3; // x = x - 3 → x is now 12 x *= 2; // x = x * 2 → x is now 24 x /= 4; // x = x / 4 → x is now 6 x %= 4; // x = x % 4 → x is now 2
🌍 Compound assignment in loops

Compound operators appear constantly in loops — accumulating totals, adjusting counters, and building values incrementally.

int total = 0;
int prices[] = {12, 35, 8, 22};
int i;
for (i = 0; i < 4; i++) {
    total += prices[i];  /* accumulate sum */
}
printf("Total: %d\n", total); /* 77 */

Topic 4

Increment & Decrement — ++ -- Prefix vs Postfix

✅ Complete

Run this — prefix and postfix look similar but produce different values in expressions. Watch line 4 vs line 7.

++ adds 1 to a variable. -- subtracts 1. Both have two forms: prefix (++x) increments first, then uses the new value. Postfix (x++) uses the current value first, then increments.

On a line alone, x++ and ++x are identical — both add 1. The difference only matters when used inside an expression: y = x++ stores old value; y = ++x stores new value.

Prefix vs Postfix
int x = 5; /* Prefix — increment THEN use */ int a = ++x; // x becomes 6, a = 6 /* Postfix — use THEN increment */ x = 5; // reset int b = x++; // b = 5 (old), x becomes 6 /* On its own line, both are identical */ x++; // same as ++x; // both add 1 to x
💡
Best Practice
Use x++ or ++x on their own lines to avoid confusion. Mix them into expressions only when the difference is intentional and clear.
🌍 Increment in for loops

i++ in a for loop is the most common use. It appears in virtually every C loop ever written.

/* i++ advances the counter each iteration */
for (int i = 0; i < 10; i++) {
    printf("Step %d\n", i);
}

/* Countdown with decrement */
for (int i = 5; i > 0; i--) {
    printf("%d...\n", i);
}

Topic 5

Operator Precedence — Order of Evaluation

✅ Complete

Run this — predict what each expression evaluates to before running.

C follows the same precedence rules as mathematics: *, /, % evaluate before + and -. When operators have equal precedence, they evaluate left to right.

Parentheses () override everything — they always evaluate first. When in doubt, add parentheses. Explicit is better than relying on precedence rules you might misremember.

Precedence Rules
/* High precedence: ++ -- (postfix) then * / % then + - */ 2 + 3 * 4 → 14 // * before + (2 + 3) * 4 → 20 // () override 10 - 2 + 3 → 11 // left to right 10 / 2 * 3 → 15 // left to right: (10/2)*3 /* Parentheses are free — use them liberally */ int result = ((a + b) * c) - (d / e);
🌍 Parentheses prevent precedence bugs

In financial and scientific code, precedence bugs cause expensive errors. Parentheses remove all ambiguity.

/* Simple interest formula: P * r * t */
float interest = principal * rate * time;

/* Compound interest — parentheses required */
float compound = principal * (1.0 + rate / 12.0);

/* Average of two values — parentheses required! */
int mid = (a + b) / 2;   /* NOT: a + b / 2 — that is a + (b/2) */

Topic 6

Arithmetic with Different Types — Type Mixing

✅ Complete

Run this — when int meets float, something has to give. See which type wins.

When you mix int and float in an expression, C automatically promotes the int to float before computing. This is called implicit type conversion. The result is always float when float is involved.

The rule is: the less precise type gets promoted to the more precise type. int → float → double. This happens automatically — you do not write anything extra.

When you store a float result in an int variable, the decimal is truncated (not rounded). int x = 3.9 gives x = 3.

Type Promotion Rules
int a = 5; float b = 2.0; float c = a + b; // int promoted to float → 7.0 float d = a * b; // int promoted to float → 10.0 float e = a / b; // int promoted to float → 2.5 /* Storing float into int truncates (drops decimal) */ int f = a + b; // 7.0 stored as 7 (truncated) int g = 3.9; // → 3, NOT 4 (no rounding!)
🌍 Type mixing in calculations

Understanding promotion prevents subtle bugs in calculations. Mix deliberately and always verify the type of the result.

int students = 30;
int passed = 24;

/* Percentage: need float result */
float pct = (float)passed / students * 100.0;
printf("Pass rate: %.1f%%\n", pct); /* 80.0% */

/* Without cast: 24/30 = 0 (integer division!) */
