Project 1

GPA Calculator

In Progress
📋 Project Brief

Build a student GPA calculator. The program stores a fixed roster of students, each with a name, ID, and set of subject grades. It computes each student's GPA (average of their grades on a 5.0 scale), prints a formatted report, and identifies the top performer.

typedef struct arrays of structs functions loops float averaging

Run this first. This is a minimal version — one student, hardcoded grades. Understand the core calculation before building the full system.

Full design: typedef struct Student with grades array, computeGPA function, formatted report

The complete GPA calculator needs a Student struct with name (char array), id (int), grades array (float[5]), and computed gpa (float). A computeGPA function receives a pointer to a Student and fills in the gpa field by averaging the grades. A printStudent function outputs a formatted row. The main block loops over an array of students.

Separating computation from display is a key software design principle — the function that calculates GPA doesn't need to know how to print. The function that prints doesn't need to know how GPA is calculated.

Project Structure
typedef struct { char name[30]; int id; float grades[5]; float gpa; } Student; void computeGPA(Student *s) { float sum = 0; int i; for (i = 0; i < 5; i++) sum += s->grades[i]; s->gpa = sum / 5.0f; } void printStudent(Student s) { printf("%-12s ID:%d GPA:%.2f\n", s.name, s.id, s.gpa); }
💡
Pass a pointer to modify; pass a value to read-only display
computeGPA(Student *s) takes a pointer because it writes the gpa field. printStudent(Student s) takes a copy because it only reads — and for a small struct, the copy cost is fine. This pattern keeps the intent of each function clear.

Build the data structure. Define the Student typedef struct with all 4 fields. Declare an array of 3 students with hardcoded data. Loop and print each student's name and id to confirm the struct works.

Add the computeGPA function. Call it for each student, then print name + computed GPA in a loop.

Complete the project. Add a loop to find the top GPA. Print the full formatted report with all students, then announce the top performer.

🌍 This is real software

School management systems, grade portals, and LMS platforms all implement this exact pattern at their core — a roster of records, per-record computation, sorted reporting. Your GPA calculator is a miniature version of software used by millions of students.

Inventory System

In Progress
📋 Project Brief

Build a product inventory manager. The system stores a fixed catalogue of products, each with an id, name, quantity, and price. It prints the full inventory table, calculates each product's total stock value (qty × price), computes the total inventory value, and finds the most expensive item.

typedef struct arrays of structs #define constants formatted printf search loop

Run this. A single product struct — see how data is stored and displayed before expanding to a full inventory.

Full design: Product struct, catalogue array, formatted table, totals, search

The complete inventory needs a Product typedef struct with id (int), name (char[30]), qty (int), and price (float). A #define MAX_PRODUCTS constant controls the catalogue size. Functions handle display and search separately. The total value is computed as a running sum through the loop; the most expensive item is found by tracking the max price index.

Formatted column output uses printf width specifiers: %-20s left-aligns a string in a 20-character column, %8.2f right-aligns a float with 2 decimal places. This produces the clean tabular output typical of inventory reports.

Project Structure
#define MAX_PRODUCTS 5 typedef struct { int id; char name[30]; int qty; float price; } Product; void printHeader() { printf("%-4s %-20s %6s %10s %12s\n", "ID", "Name", "Qty", "Price", "Total Value"); printf("%-4s %-20s %6s %10s %12s\n", "----","--------------------","------","----------","------------"); } void printProduct(Product p) { printf("%-4d %-20s %6d %10.2f %12.2f\n", p.id, p.name, p.qty, p.price, p.qty * p.price); }
💡
printf width specifiers produce aligned tabular output
%-20s = left-align in 20 chars. %6d = right-align int in 6 chars. %10.2f = right-align float in 10 chars with 2 decimal places. The negative sign means left-align; positive (default) means right-align. Consistent widths across every row produce a clean table.

Build the data layer. Define the Product struct and create a catalogue array of 4 products. Print each product's id and name in a loop to confirm the data is stored correctly.

Add the formatted table. Print a header row, then loop and print each product with qty × price total value per row.

Complete the system. Add a second pass: sum all total values into a grand total. Find the most expensive item (highest unit price). Print both results below the table.

🌍 This is real software

POS systems, warehouse management software, and e-commerce backends all have this same core: a product record, a catalogue, and functions to query and report on it. The difference between your version and a production system is persistence (database) and scale (millions of records) — the logic is identical.

Project 3

Number Guessing Game

In Progress
📋 Project Brief

Build a number-guessing game simulator. Since the browser has no keyboard input, the guesses come from a pre-set array — letting you control the full sequence and test every branch. The program: picks a secret number, processes each guess in turn (printing "Too low", "Too high", or "Correct!"), counts attempts, and reports the result.

arrays as input if / else if for loop break counters & flags enum GameState

Run this minimal version. A secret number and one guess — see the core comparison logic before adding the full game loop.

Full design: guess array as simulated input, loop with break, attempt counter, win/lose tracking

The full game replaces keyboard input with a guesses[] array. A for loop processes each guess: print "Too low", "Too high", or "Correct!" and break. An int attempts counter tracks how many guesses were processed. A won flag (set to 1 on correct) determines the final message after the loop.

An enum GameState { PLAYING, WON, LOST } makes the state tracking readable. The secret number can be any constant — change it to test all branches of your logic without modifying the guess array.

Project Structure
int secret = 42; int guesses[] = {20, 60, 35, 45, 42}; int n = sizeof(guesses) / sizeof(guesses[0]); int attempts = 0; int won = 0; int i; for (i = 0; i < n; i++) { attempts++; printf("Guess %d: %d — ", attempts, guesses[i]); if (guesses[i] < secret) printf("Too low\n"); else if (guesses[i] > secret) printf("Too high\n"); else { printf("Correct!\n"); won = 1; break; } } if (won) printf("Won in %d attempts!\n", attempts); else printf("No more guesses. Secret was %d\n", secret);
💡
Test every branch by changing the guesses array
To test the "no more guesses" branch: make all guesses wrong. To test "correct on first try": put the secret number first. Because the input is a simple array, you have complete control over every scenario — this is the key advantage of the simulated input design for browser-based programs.

Build the game loop. Set secret=42, create the guesses array {20, 60, 35, 45, 42}. Loop, print each guess and its result (Too low / Too high / Correct!). Break on correct. Count attempts.

Add the win/lose outcome. After the loop, print the result: "Won in N attempts!" if the correct guess was found, or "Out of guesses! Secret was N." if the loop exhausted all guesses.

Complete the game. Add an enum GameState for PLAYING / WON / LOST. Print a difficulty rating based on attempts: 1-2 guesses = "Excellent", 3-4 = "Good", 5+ = "Keep practicing".

🌍 This is real software

The guessing game logic — a target, a comparison, a feedback message, an attempt counter — is exactly the pattern behind binary search, spell checkers, and feedback systems. Binary search is just an optimal guessing strategy: always guess the middle. Your game engine is a direct ancestor of those algorithms.
