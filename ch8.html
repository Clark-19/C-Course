Chapter 8

If / Else

Every program that makes decisions uses if and else. This chapter covers how to write single conditions, two-way branches, multi-way chains, nested decisions, and the compact ternary shorthand — the full toolkit for controlling which code runs and when.

5 Topics if · if-else · else if · nested · ternary
Topic 1

The if Statement — Running Code Conditionally

In Progress

Run this. The if block only executes when the condition is non-zero.

if runs the block only when the condition is true (non-zero)

The condition inside if (...) is evaluated. If it is non-zero (true), the body runs. If it is zero (false), the body is skipped entirely. Execution then continues with whatever comes after the if block regardless.

The body can be a single statement (no braces needed) or a block of multiple statements (curly braces required). Always use braces — it prevents a common bug where adding a second statement accidentally falls outside the if.

if — Two Forms
/* Single statement — braces optional but risky */ if (condition) single_statement; /* Block — braces always recommended */ if (condition) { statement_one; statement_two; /* ... */ } /* Inline — valid but hard to read */ if (x > 0) printf("positive\n");
⚠
Always Use Braces
Without braces, only the very next statement belongs to the if. Adding a second line later will not be conditional — it always runs, silently. Use { } every time, even for single statements.
🌍 Input validation in every program

Every application that accepts user input uses if to validate it before processing. Unconditional code that never checks its inputs is unsafe.

int quantity = 5;
float price   = 29.99;

if (quantity <= 0) {
    printf("Error: quantity must be positive\n");
}
if (price <= 0.0) {
    printf("Error: price must be positive\n");
}
if (quantity > 0 && price > 0.0) {
    printf("Total: %.2f\n", quantity * price);
}

Topic 2

if / else — Two-Way Branching

In Progress

Run this. Exactly one of the two branches runs — never both, never neither.

if/else guarantees exactly one branch runs

Adding else creates a two-way branch. Exactly one of the two bodies will execute on every run — the if body when the condition is true, the else body when it is false. There is no case where both run or neither runs.

This is fundamentally different from two separate if statements. With separate ifs, both could run if both conditions are true, or neither could run if both are false. if/else forces a guaranteed choice.

if / else Syntax
if (condition) { /* runs when condition is TRUE */ statement_a; } else { /* runs when condition is FALSE */ statement_b; } /* exactly one of the above always runs */ /* Real example */ int score = 72; if (score >= 60) { printf("Pass\n"); } else { printf("Fail\n"); }
🌍 Two-way decisions in real programs

Any toggle, binary state, or on/off decision is naturally a two-way branch. if/else maps directly to these situations.

int is_authenticated = 1;

if (is_authenticated) {
    printf("Welcome! Loading your dashboard.\n");
} else {
    printf("Please log in to continue.\n");
}

int temperature = 15;
printf("It is %s outside.\n",
       (temperature >= 20) ? "warm" : "cool");

Topic 3

else if — Multi-Way Branching

In Progress

Run this. Only the first matching condition runs — the rest are skipped.

else if chains test conditions in order — first match wins

An else if chain tests conditions one by one from top to bottom. The moment one condition is true, that body runs and all remaining else if and else blocks are skipped — even if later conditions would also be true.

This is why order matters in an else if chain. If you check score >= 60 before score >= 90, a score of 95 would match the first condition and never reach the A-grade check.

else if Chain — First Match Wins
if (condition_1) { /* runs if condition_1 is true */ } else if (condition_2) { /* runs if condition_1 false AND condition_2 true */ } else if (condition_3) { /* runs if 1 and 2 false AND condition_3 true */ } else { /* runs if ALL conditions above were false */ } /* Grade example — order matters: high to low */ int score = 85; if (score >= 90) printf("A\n"); else if (score >= 80) printf("B\n"); /* matches here */ else if (score >= 70) printf("C\n"); /* skipped */ else printf("F\n"); /* skipped */
⚠
Order of Conditions Matters
Put more specific conditions before broader ones. Check for the highest range first in a grade classifier, the most restrictive case first in validation. Once a match fires, the rest of the chain is skipped.
🌍 HTTP status codes via else if

Classifying status codes, error levels, or response types is a natural else if chain — each range maps to one category.

int status = 404;

if      (status >= 500) printf("Server error\n");
else if (status >= 400) printf("Client error\n");   /* matches */
else if (status >= 300) printf("Redirect\n");
else if (status >= 200) printf("Success\n");
else                    printf("Informational\n");

Topic 4

Nested if — Decisions Inside Decisions

In Progress

Run this. The inner if only runs when the outer if already passed.

Nested if — a second decision inside the first

Any if body can itself contain another if. This is called nesting. The inner if is only reached if the outer condition was already true, which implicitly gates all inner logic.

Nesting is powerful but can get hard to read. Deeper than 2–3 levels is usually a sign to refactor using && conditions or helper logic. The dangling else problem — where it is ambiguous which if an else belongs to — is also introduced here. Braces resolve it.

Nested if — Structure
if (outer_condition) { /* only here if outer is true */ if (inner_condition) { /* only here if BOTH are true */ statement_a; } else { /* outer true, inner false */ statement_b; } } else { /* outer was false — inner never tested */ statement_c; } /* Dangling else — always use braces to avoid ambiguity */ if (a) if (b) printf("both\n"); else /* which if does this belong to? */ printf("???\n");
💡
Dangling else rule
In C, an else always belongs to the nearest preceding if that does not yet have an else. Always use braces to make the association explicit and avoid silent bugs.
🌍 Multi-level access control

Nested if naturally models layered conditions — you must pass the outer gate before the inner gate is even checked.

int logged_in   = 1;
int is_admin    = 1;
int account_ok  = 1;

if (logged_in) {
    if (account_ok) {
        if (is_admin) {
            printf("Admin panel\n");
        } else {
            printf("User dashboard\n");
        }
    } else {
        printf("Account suspended\n");
    }
} else {
    printf("Please log in\n");
}

Topic 5

The Ternary Operator — condition ? a : b

In Progress

Run this. The ternary is a compact if/else that evaluates to a value.

Ternary — an expression, not just a statement

The ternary operator (?:) is the only C operator that takes three operands. It evaluates a condition and produces one of two values: condition ? value_if_true : value_if_false.

Because it is an expression (it produces a value), you can use it inside printf, assignments, function calls, or anywhere a value is expected. An if/else statement cannot be used that way — it is a statement, not an expression.

Best used for simple, two-way value selections. Avoid nesting ternaries — it produces unreadable code. For complex logic, use if/else.

Ternary Syntax
condition ? value_if_true : value_if_false /* Assign the result */ int max = (a > b) ? a : b; /* Use directly in printf */ printf("%s\n", (score >= 60) ? "Pass" : "Fail"); /* Equivalent if/else */ if (score >= 60) printf("Pass\n"); else printf("Fail\n"); /* Avoid nesting — unreadable */ /* int r = a > b ? a > c ? a : c : b > c ? b : c; */
💡
When to use ternary
Use ternary when selecting between two simple values inline. Use if/else when there is more than one statement per branch or when logic gets complex.
🌍 Ternary for concise value selection

Ternary shines when you need to pick a label, message, or value inline — it keeps code short without sacrificing clarity.

int items = 1;
printf("You have %d item%s\n",
       items,
       (items == 1) ? "" : "s");   /* pluralize */

float discount = 0.0;
int is_member  = 1;
discount = is_member ? 0.10 : 0.0;
printf("Discount: %.0f%%\n", discount * 100);
