Chapter 3

Input & Output

printf() and scanf() are your two primary tools for communicating with the user. This chapter teaches you to control output with precision — width, padding, alignment — and to read data back in.

8 Topics printf · scanf · format specifiers · getchar
Topic 1

printf() — Sending Output to the Screen

✅ Complete

Compile and run this — printf() is how C talks to you. See every detail it can produce.

printf() — "print formatted" — sends text to the screen. Everything inside the double quotes is printed exactly, except format specifiers (starting with %) and escape sequences (starting with \).

The format string and the variables to substitute are separated by commas inside the parentheses. Each %d, %f, %c in the string gets replaced by the next variable in the list.

Every printf() call requires #include <stdio.h> — that header is what makes the function available.

printf() Anatomy
printf( "format string", var1, var2, ... ); ↑ ↑ ↑ required: variables substituted always a string for each %specifier
💡
Escape Sequences
\n = new line  ·  \t = tab  ·  \\ = backslash  ·  \" = double quote  ·  %% = literal percent sign
🌍 printf() in every real C program

Every C program uses printf() for output — from "Hello, World!" to diagnostic logs in operating systems. printf() is the Swiss army knife of C output.

printf("Error: file not found (code %d)\n", error_code);
printf("[%02d:%02d:%02d] Server started\n", h, m, s);

Topic 2

Format Specifiers — %d %f %c %s %ld %lf

✅ Complete

Run this — six different format specifiers, one for each common type.

A format specifier is a placeholder in the printf() string that gets replaced by a variable's value. The specifier must match the variable's type — using the wrong one gives incorrect output or undefined behavior.

The six essential specifiers: %d (int), %f (float/double), %c (char), %s (string/char array), %ld (long), %lf (double in scanf — in printf %f works for both).

Format Specifier Reference
%d → int (decimal integer) %ld → long (long integer) %lld → long long (long long integer) %f → float/double (floating-point, default 6 decimal places) %lf → double (scanf) (use %f in printf — same result) %c → char (single character) %s → char array (string / null-terminated array) %u → unsigned int (unsigned decimal) %p → pointer (memory address, hex format)
⚠
Common Mistake — Type Mismatch
Using %d for a float or %f for an int produces garbage output. The specifier must match the variable's actual type. int score = 85; printf("%f", score); — do not do this.
🌍 Mixed types in a single printf()

Real programs print many types at once. A student record, a sensor reading, an error message — all mix specifiers in one printf().

printf("Student %d: %s  GPA: %.2f  Grade: %c\n",
       id, name, gpa, letter_grade);

Topic 3

Format Modifiers — Width, Precision, Padding

✅ Complete

Run this — the same values, formatted with different widths and precision. Look at how alignment changes.

Format modifiers go between the % and the type letter. Width sets the minimum number of characters printed — values pad with spaces on the left. Precision (.n) controls decimal places for floats or max characters for strings.

A - flag left-aligns instead of right-aligning. A 0 flag pads with zeros instead of spaces. These tools build aligned tables and formatted reports.

Modifier Syntax
%[flags][width][.precision]type %10d → right-align int in 10-char field %-10d → left-align int in 10-char field %010d → pad int with zeros (0000000042) %.2f → float with exactly 2 decimal places %8.2f → 8-wide field, 2 decimal places %-8.2f → left-aligned, 8-wide, 2 decimals
🌍 Formatted tables in reports

Alignment modifiers build readable tables without any external library. Student grade reports, financial summaries, server logs — all use width modifiers.

printf("%-15s %5s %8s\n", "Name", "Grade", "Score");
printf("%-15s %5c %8.2f\n", "Alice", 'A', 97.5);
printf("%-15s %5c %8.2f\n", "Bob", 'B', 83.1);

Topic 4

scanf() — Reading User Input

✅ Complete

Run this — scanf() reads input. The editor pre-fills the input below the compiler. See how the value gets into your variable.

scanf() reads formatted input and stores it in variables. The critical difference from printf(): scanf() needs the address of each variable — you must pass &variable, not just variable.

The & (address-of) operator gives scanf() the memory location where it should write the input. Without it, scanf() writes to a random memory location — a serious bug.

Use the same format specifiers as printf(): %d for int, %f for float, %lf for double, %c for char.

scanf() Anatomy
scanf( "%d", &number ); ↑ ↑ format str &variable (& is mandatory!) /* Reading different types */ int age; scanf("%d", &age); float price; scanf("%f", &price); double lat; scanf("%lf", &lat); /* note: %lf for double in scanf */ char ch; scanf(" %c", &ch); /* note: space before %c */
⚠
Critical Mistake — Forgetting &
scanf("%d", number); — WRONG. Without &, scanf() crashes or corrupts memory. Always: scanf("%d", &number);
🌍 scanf() in real programs

Every interactive C program uses scanf(). A calculator reads two numbers. A login screen reads a username. An ATM reads an account number.

int account_number;
float withdrawal;
printf("Account: "); scanf("%d", &account_number);
printf("Amount:  "); scanf("%f", &withdrawal);

Topic 5

scanf() with Multiple Inputs

✅ Complete

Run this — one scanf() can read multiple values at once. The input is pre-filled for you.

One scanf() can read multiple values by listing multiple format specifiers and their corresponding &variable pairs. The input values must be separated by whitespace (spaces, tabs, or newlines) — scanf() skips whitespace between values.

Or use separate scanf() calls — one per variable. Both approaches work. Separate calls are easier to read and debug, especially for beginners.

Multiple Input Patterns
/* Option 1: one scanf, multiple values */ scanf("%d %d %f", &a, &b, &price); /* Input: 10 20 9.99 (space-separated) */ /* Option 2: separate scanf calls — clearer */ scanf("%d", &a); scanf("%d", &b); scanf("%f", &price); /* Each call waits for one value on its own line */
🌍 Reading a date from input

Programs that read structured input (dates, coordinates, dimensions) use multi-value scanf() frequently.

int day, month, year;
printf("Enter date (dd mm yyyy): ");
scanf("%d %d %d", &day, &month, &year);
printf("Date: %02d/%02d/%04d\n", day, month, year);

Topic 6

Input Buffer — The Most Common scanf() Trap

✅ Complete

Run this — notice why reading a char after an int causes a skip. This is the #1 scanf() bug in beginner C programs.

When you press Enter after typing a number, the \n (newline) stays in the input buffer. The next scanf("%c", &ch) immediately reads that leftover \n instead of waiting for your input.

The fix is simple: add a space before %c in the format string: scanf(" %c", &ch). The space tells scanf() to skip all whitespace (including the leftover newline) before reading the character.

An alternative fix is getchar() to consume the leftover newline before the char scanf().

The Buffer Fix
int age; char grade; scanf("%d", &age); /* reads number, leaves \n in buffer */ scanf(" %c", &grade); /* CORRECT: space skips leftover \n */ /* NOT: scanf("%c", &grade); — would read the \n, not a letter */ /* Alternative fix using getchar() */ scanf("%d", &age); getchar(); /* consumes the leftover \n */ scanf("%c", &grade);
🌍 The buffer bug costs hours of debugging

Every C programmer has spent hours on this bug at least once. Knowing about it and knowing the fix saves you that frustration permanently.

/* Pattern to always remember: */
int score;
char letter_grade;
scanf("%d", &score);
scanf(" %c", &letter_grade); /* the space is the fix */

Topic 7

getchar() and putchar()

✅ Complete

Run this — getchar() and putchar() work one character at a time. See what they do.

getchar() reads exactly one character from input — including spaces and newlines. It returns an int (not char) so it can also return EOF when input ends. putchar() prints exactly one character to output.

These functions are faster than printf/scanf for single-character I/O and are essential for reading characters in loops — processing input one character at a time until EOF.

getchar() / putchar()
int c = getchar(); /* reads one char, returns int */ putchar(c); /* prints one char */ putchar('\n'); /* prints newline */ /* Loop: process every character until Enter */ int ch; while ((ch = getchar()) != '\n') { putchar(ch); /* echo each character back */ }
💡
Why int, not char?
getchar() returns int because it must be able to return EOF (typically -1), which cannot fit in a char. Always store the result of getchar() in an int.
🌍 getchar() for input processing

The classic C idiom for processing a line of input character-by-character is built on getchar(). It appears in text processors, parsers, and compilers.

int c;
int count = 0;
while ((c = getchar()) != '\n' && c != EOF) {
    count++;  /* count characters on the line */
}
printf("You typed %d characters\n", count);

Topic 8

Formatted Output — Aligning Columns

✅ Complete

Run this — a properly aligned table built entirely with printf() modifiers.

Column alignment combines width (%10d), left-align (%-10s), and precision (%8.2f) across multiple printf() calls. The key principle: every row uses the same format string, so the columns automatically line up.

The header row and data rows must use identical widths — change one and the whole table shifts. Print a separator line with printf("%.40s\n", "---..."); or a loop of dashes.

Column Alignment Pattern
/* Define column widths once at the top */ printf("%-15s %5s %10s\n", "Name", "Grade", "Score"); printf("%-15s %5s %10s\n", "----------", "-----", "----------"); printf("%-15s %5c %10.2f\n", "Alice Tan", 'A', 97.5); printf("%-15s %5c %10.2f\n", "Bob Cruz", 'B', 83.1); /* Output: Name Grade Score ---------- ----- --------- Alice Tan A 97.50 Bob Cruz B 83.10 */
🌍 Column tables in real systems

System tools like ls -l, ps aux, and top are all built using exactly this technique — fixed-width printf() columns.

printf("%-8s %6s %8s %s\n", "USER", "PID", "MEM%", "COMMAND");
printf("%-8s %6d %7.1f%% %s\n", "root", 1, 0.5, "systemd");
printf("%-8s %6d %7.1f%% %s\n", "student", 1042, 2.3, "main");
