Chapter 1

Variables & Constants

Variables are named containers for data. You declare them, assign values, and use those values throughout your program. This chapter covers every variable type in C — by writing code, not by reading definitions.

8 Topics int · float · double · char · const · #define
Topic 1

What is a Variable?

✅ Complete

Compile and run this — a variable stores a number.

A variable is a named storage location in memory. You declare it with a type and a name, then assign it a value with =.

int score = 95; creates a box named score, tells C it holds a whole number (int), and puts 95 inside it.

%d inside printf() is a placeholder — it tells C to print the integer value of whatever variable you list after the comma.

Syntax — Variable Declaration
type variable_name = value; // ──────────────────────────── int score = 95; float temperature = 36.6; char grade = 'A'; // ↑ type ↑ name ↑ value
💡
Remember
Every variable must be declared before it is used. C does not let you use a name that has never been defined — the compiler will error: undeclared identifier.
🌍 Variables in real programs

Every game, app, and operating system tracks data with variables — player health, sensor readings, file sizes. The pattern is always the same: declare, assign, use.

int player_health = 100;
int enemy_damage  = 15;
player_health = player_health - enemy_damage;
printf("Health: %d\n", player_health); /* prints 85 */

Topic 2

Variable Naming Rules — Identifiers

✅ Complete

Run this — only the valid declarations compile. See which names work.

In C, variable names are called identifiers. An identifier must follow exactly these rules — break any one of them and the compiler errors.

  • May only contain letters, digits, and underscores (_)
  • Must not start with a digit — 1score is invalid, score1 is valid
  • Case-sensitive — score and Score are two different variables
  • Must not be a C keyword — you cannot name a variable int, return, or for
  • Must not contain spaces — my score is two tokens, not one name
Valid vs Invalid Names
/* ✓ VALID */ /* ✗ INVALID — why */ score 1score ← starts with digit player_health my score ← contains space _temp int ← C keyword totalCount first-name ← hyphen not allowed x for ← C keyword
⚠
Common Mistake
float, char, int, return — these are keywords. You cannot use them as variable names. The compiler will give a confusing error if you try. Name your variables after what they represent: temperature, grade, count.
🌍 Names matter in real code

Professional C code uses names that describe what the variable holds — not single letters (except loop counters). Readable names make code maintainable.

/* ✗ Hard to read */
int x = 86400;
/* ✓ Self-documenting */
int seconds_per_day = 86400;

Topic 3

int Variables — Whole Numbers

✅ Complete

Run this — int stores whole numbers. Watch what happens with arithmetic.

int stores whole numbers — positive, negative, or zero. It takes 4 bytes of memory and holds values from roughly −2 billion to +2 billion.

Declare multiple int variables in one line by separating them with commas: int a, b, c;

Use %d as the format specifier when printing an int with printf().

int — Declaration Forms
int count; /* declare only — value is garbage */ int score = 0; /* declare and initialize */ int a, b, c; /* declare multiple on one line */ int x = 10, y = 20; /* declare and initialize multiple */ printf("%d\n", score); /* %d is the int format specifier */
⚠
Common Mistake — Uninitialised int
Writing int count; and then using count without assigning a value first is undefined behavior. C does not automatically set variables to 0 — the memory may contain garbage from a previous program. Always initialise: int count = 0;
🌍 int in real programs

int is used for anything that is counted or indexed — loop counters, array sizes, user IDs, scores. When you need bigger numbers, use long or long long.

int total_students = 42;
int passed = 0;
int failed  = 0;
/* program logic goes here */
printf("Passed: %d  Failed: %d\n", passed, failed);

Topic 4

float & double — Decimal Numbers

✅ Complete

Run this — observe how float and double handle decimal numbers differently.

float stores decimal (floating-point) numbers in 4 bytes with about 6–7 digits of precision. double uses 8 bytes and gives 15–16 digits of precision.

Use %f for both float and double in printf(). Control decimal places with %.2f (2 places), %.4f (4 places), etc.

Prefer double over float for most calculations — the extra precision prevents subtle rounding errors.

float and double
float price = 9.99; /* 4 bytes — ~6 digits precision */ double pi = 3.14159265358979; /* 8 bytes — ~15 digits */ printf("%f\n", price); /* 9.990000 (default 6 decimal places) */ printf("%.2f\n", price); /* 9.99 (2 decimal places) */ printf("%.4f\n", pi); /* 3.1416 (4 decimal places) */
↔
float vs double
float price = 9.99; — 4 bytes, ~6 significant digits. Use when memory is very tight.
double pi = 3.14159; — 8 bytes, ~15 significant digits. Use for all scientific, financial, or precise calculations. In modern C, prefer double.
🌍 float & double in real programs

Temperature sensors, GPS coordinates, financial calculations, physics simulations — anything measured with a decimal value uses float or double.

double latitude  = 10.3157;   /* Manolo Fortich, Bukidnon */
double longitude = 125.0000;
double temperature_celsius = 28.5;
printf("Temp: %.1f C\n", temperature_celsius); /* 28.5 C */

Topic 5

char Variables — Single Characters

✅ Complete

Run this — char stores one character. Notice the single quotes and %c.

char holds a single character — a letter, digit, or symbol — stored as its ASCII code (a number from 0–127). It takes only 1 byte of memory.

Character values are always wrapped in single quotes: 'A', 'z', '5', '!'. Double quotes are for strings — a completely different type.

Use %c in printf() to print the character. Use %d on a char to see its ASCII number.

char — Declaration and Use
char grade = 'A'; /* single quotes — always */ char symbol = '!'; char digit = '7'; /* the character 7, not the number 7 */ printf("%c\n", grade); /* prints: A */ printf("%d\n", grade); /* prints: 65 (ASCII code of 'A') */
⚠
Single vs Double Quotes
'A' — single quotes — is a char (one character).
"A" — double quotes — is a string (a char array, completely different type).
Using char grade = "A"; is a type error the compiler will catch.
🌍 char in real programs

char is the building block of all text in C — strings are arrays of char. A single char often represents a menu choice, a yes/no flag, or a single letter grade.

char menu_choice = 'A';
char pass_fail   = 'P';
char first_initial = 'M';
printf("Choice: %c  Result: %c\n", menu_choice, pass_fail);

Topic 6

Constants — the const Keyword

✅ Complete

Run this — const creates a value that cannot change. Try the second program to see the error.

Add const before a variable declaration to make it a constant — a value that is set once and can never be changed. If you try to assign a new value, the compiler errors.

By convention, constant names are written in UPPER_CASE with underscores. This signals to anyone reading the code that this value is fixed.

Constants are ideal for values that should never change: mathematical constants, array sizes, tax rates, speed of light.

const — Declaration
const int MAX_STUDENTS = 30; const double PI = 3.14159265358979; const char PASS_GRADE = 'P'; /* Using the constant */ printf("Max class size: %d\n", MAX_STUDENTS); /* This would be a compile error: */ /* MAX_STUDENTS = 50; */ /* ✗ error: assignment to const */
💡
Why Use Constants?
If your program uses the number 3.14159 in 20 places and you need to change the precision, you would have to find and change all 20. With const double PI = 3.14159;, you change it in one place. Constants also prevent accidental modification.
🌍 const in real programs

Constants define the fixed properties of a system — buffer sizes, physical constants, port numbers, error codes. Every professional C codebase uses them to prevent magic numbers.

const int    MAX_BUFFER    = 1024;
const double GRAVITY       = 9.81;
const int    HTTP_OK       = 200;
const int    HTTP_NOT_FOUND = 404;

Topic 7

#define — Preprocessor Constants

✅ Complete

Run this — #define creates a constant before the compiler even runs.

#define is a preprocessor directive — it runs before the compiler and does a simple text substitution. Every time the preprocessor sees MAX in your code, it replaces it with 100 before compilation begins.

#define has no type and no semicolon. It is just a name-to-text replacement rule.

Like const, convention is UPPER_CASE for #define constants.

#define vs const
/* #define — preprocessor, no type, no semicolon, no = */ #define MAX_STUDENTS 30 #define PI 3.14159 #define PASS_GRADE 'P' /* const — typed, has a value, lives in memory */ const int MAX = 30; const double PI2 = 3.14159; /* Both work the same way in usage: */ printf("Max: %d\n", MAX_STUDENTS); printf("Max: %d\n", MAX);
↔
#define vs const — Key Differences
#define — no type checking, no memory allocation, replaced by text before compile. Older style, common in legacy C code.
const — has a type, stored in memory, type-checked by compiler. Safer and preferred in modern C (C99 and later).
🌍 #define in real C code

#define is everywhere in C headers and legacy code — it predates const by decades and is still heavily used for feature flags and configuration.

#define SCREEN_WIDTH   1920
#define SCREEN_HEIGHT  1080
#define VERSION_MAJOR  2
#define VERSION_MINOR  4

printf("Version %d.%d\n", VERSION_MAJOR, VERSION_MINOR);

Topic 8

Naming Conventions in C

✅ Complete

Run this — all three styles compile, but only one is standard C convention.

C has no enforced naming style — but the community convention is clear and nearly universal.

Use snake_case (all lowercase with underscores) for variables and functions. Use UPPER_SNAKE_CASE for constants (const and #define). Use short names like i, j, k only for loop counters.

Consistent naming makes code readable months later — by you and by anyone else who reads it.

C Naming Convention Summary
/* Variables and functions: snake_case */ int student_count = 0; double account_balance = 1500.00; void calculate_grade(int score) { /* ... */ } /* Constants: UPPER_SNAKE_CASE */ const int MAX_STUDENTS = 30; #define TAX_RATE 0.12 /* Loop counters: single letters are OK */ for (int i = 0; i < 10; i++) { /* ... */ } /* ✗ Avoid: camelCase, PascalCase in C */ int studentCount = 0; /* JavaScript/Java style — avoid in C */ int StudentCount = 0; /* C++ class style — avoid in C */
🌍 Naming in the Linux kernel

The Linux kernel — millions of lines of C — uses snake_case throughout. Consistent naming is enforced by code review, not the compiler.

static int total_bytes_read = 0;
const unsigned int MAX_SOCKET_BACKLOG = 128;
void update_socket_state(int fd, int new_state) {
    /* function name: snake_case */
}
