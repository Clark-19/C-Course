Chapter 10

While Loops

Every useful program repeats something. Loops are how you tell C to run the same code multiple times without copying and pasting it. This chapter covers while, do-while, counter-driven iteration, controlled stopping, and nested repetition.

5 Topics while · do-while · counter · break/continue · nested
Topic 1

The while Loop — Repeat Until False

In Progress

Run this. The body repeats as long as the condition stays true.

while checks the condition before each iteration

A while loop tests its condition at the top, before executing the body. If the condition is already false before the first iteration, the body never runs at all.

The loop continues repeating as long as the condition remains non-zero (true). The moment the condition evaluates to zero, the loop exits and execution continues with the next statement after the closing brace.

The most important part: something inside the loop must change the condition, otherwise the loop runs forever.

while Loop Structure
while (condition) { /* body: runs as long as condition is true */ /* MUST change something that affects condition */ } /* execution continues here when condition is false */ /* Typical counter pattern */ int i = 0; while (i < 5) { printf("%d\n", i); i++; /* changes condition — prevents infinite loop */ }
⚠
Infinite Loop — The Most Common While Bug
If the condition never becomes false, the loop never stops. Always verify that something inside the loop modifies the variable(s) the condition tests.
🌍 Reading until a sentinel value

while loops drive file reading, event loops, and input processing — anything that must keep going until a stopping condition is met.

int sum = 0, n = 1;

/* Add numbers until 0 is entered */
while (n != 0) {
    n = 5;         /* simulating input */
    sum += n;
    if (n == 5) n = 0;  /* simulate stop */
}
printf("Sum: %d\n", sum);

Topic 2

do-while — Run at Least Once

In Progress

Run this. Compare the while and do-while when the condition starts false.

do-while checks the condition at the bottom — body runs at least once

A do-while loop places the condition check at the end, after the body executes. This guarantees the body runs at least one time, even if the condition is immediately false.

The most common use case is menu loops and input validation: you always want to show the menu or prompt at least once before checking if the user wants to exit.

do-while Syntax
do { /* body always runs at least once */ /* then condition is checked */ } while (condition); /* semicolon required here! */ /* while vs do-while when condition starts false */ int x = 10; while (x < 5) { printf("while runs\n"); /* never prints */ } do { printf("do-while runs\n"); /* prints once */ } while (x < 5); /* then checks: false, exits */
💡
The Semicolon After while (condition)
The do-while needs a semicolon after the closing while (condition);. Forgetting it is a common syntax error. Note: regular while loops have no semicolon after their condition.
🌍 Input validation with do-while

The "ask at least once" guarantee makes do-while the natural structure for input validation loops — prompt the user, check, repeat if invalid.

int tries = 0;

do {
    tries++;
    printf("Attempt %d: ", tries);
    /* simulating user input */
} while (tries < 3);

printf("Done after %d tries.\n", tries);

Topic 3

Counter-Controlled Loops — Counting Up, Down, and by Steps

In Progress

Run this — the same structure, different counting patterns.

Counter-controlled loops use a variable to track iterations

Every counter-controlled loop has the same three parts: an initializer (set counter before the loop), a condition (test counter in while), and an update (change counter inside the body). Missing any one of these causes bugs — usually infinite loops or loops that never run.

You are not limited to +1 increments. You can count by 2s, 5s, 10s, count down, or adjust non-linearly. The counter can be used inside the loop body for calculations that depend on the iteration number.

Counter Patterns
/* Count up by 1 */ int i = 0; while (i < 5) { printf("%d ", i); i++; } /* 0 1 2 3 4 */ /* Count down */ int n = 5; while (n > 0) { printf("%d ", n); n--; } /* 5 4 3 2 1 */ /* Count by 2s */ int k = 0; while (k <= 10) { printf("%d ", k); k += 2; } /* 0 2 4 6 8 10 */ /* Use counter in calculation */ int j = 1; while (j <= 5) { printf("%d^2=%d\n", j, j*j); j++; }
🌍 Accumulating totals in loops

Counter-driven loops accumulate results across iterations — summing, multiplying, or building values step by step.

/* Sum of 1 to 100 */
int total = 0, i = 1;
while (i <= 100) {
    total += i;
    i++;
}
printf("Sum 1-100: %d\n", total);  /* 5050 */

/* Factorial of 6 */
int fact = 1, n = 6;
while (n > 1) { fact *= n; n--; }
printf("6! = %d\n", fact);  /* 720 */

Topic 4

break and continue — Controlling the Loop Mid-Run

In Progress

Run this — both keywords change what happens in the middle of an iteration.

break exits the loop; continue skips to the next iteration

break immediately exits the entire loop. Execution jumps to the first statement after the closing brace. All remaining iterations are cancelled.

continue skips the rest of the current iteration's body and jumps back to check the condition again for the next iteration. The loop does not exit — it just skips to the next cycle.

Both are typically used inside an if condition so they only trigger when a specific situation is met.

break vs continue
int i = 0; /* break — stop early */ while (i < 10) { if (i == 5) break; /* exit when i hits 5 */ printf("%d ", i); /* prints 0 1 2 3 4 */ i++; } /* continue — skip this iteration */ i = 0; while (i < 6) { i++; if (i == 3) continue; /* skip printing 3 */ printf("%d ", i); /* prints 1 2 4 5 6 */ }
🌍 Search with break, filter with continue

break stops a search the moment a result is found. continue skips items that do not match a filter — two of the most common loop patterns in real programs.

/* Search: stop at first match */
int data[] = {4, 7, 2, 9, 1};
int target = 9, found = 0, i = 0;
while (i < 5) {
    if (data[i] == target) { found = 1; break; }
    i++;
}
printf("Found: %d\n", found);

/* Filter: skip negatives, sum positives */
int vals[] = {3, -1, 5, -2, 4};
int sum = 0; i = 0;
while (i < 5) {
    if (vals[i] < 0) { i++; continue; }
    sum += vals[i]; i++;
}

Topic 5

Nested While Loops — Loops Inside Loops

In Progress

Run this. For every outer iteration, the inner loop runs all the way through.

Nested loops: inner loop completes fully for each outer iteration

When a while loop is inside another while loop, the inner loop runs completely for each single iteration of the outer loop. If the outer runs 3 times and the inner runs 4 times, the total body executions are 3 × 4 = 12.

A critical rule: the inner loop counter must be reset at the top of each outer iteration. If you initialize the inner counter outside the outer loop, it retains its final value from the previous outer iteration and the inner loop may not run at all after the first pass.

Nested Loop Pattern
int outer = 1; while (outer <= 3) { int inner = 1; /* reset inner counter every outer pass */ while (inner <= 3) { printf("(%d,%d) ", outer, inner); inner++; } printf("\n"); outer++; } /* (1,1)(1,2)(1,3) (2,1)(2,2)(2,3) (3,1)(3,2)(3,3) */
⚠
Always Reset the Inner Counter Inside the Outer Loop
Declare and initialize the inner counter inside the outer loop body. If declared outside, the inner loop starts where the previous outer pass left it — usually causing the inner loop to run zero times after the first pass.
🌍 Multiplication table with nested loops

Nested loops generate grids, tables, and matrices — any output that has both rows and columns naturally requires two loops.

int row = 1;
while (row <= 4) {
    int col = 1;
    while (col <= 4) {
        printf("%4d", row * col);
        col++;
    }
    printf("\n");
    row++;
}
/*    1   2   3   4
      2   4   6   8
      3   6   9  12
      4   8  12  16 */
