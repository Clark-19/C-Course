Chapter 13

Functions

Functions are how C programs are organized. Instead of one giant block of code, you break logic into named, reusable pieces — each doing exactly one thing. Write it once, call it anywhere. This chapter covers every function concept from first definition through recursion.

5 Topics void · parameters · return · scope · recursion
Topic 1

Defining and Calling Functions — void

In Progress

Run this. A function is called three times — the same code executes three times from just three calls.

A function is a named block of code you define once and call anywhere

A function definition has four parts: a return type (void means no value returned), a name, an empty parameter list (), and a body in curly braces. The function does nothing until it is explicitly called — called by writing its name followed by () and a semicolon.

Every call runs the entire body from top to bottom, then returns to where it was called. Calling it 100 times runs the body 100 times. The code inside is written once; the behavior is repeated through calls.

void Function — Define and Call
/* Define: return_type name(parameters) { body } */ void greet() { printf("Hello!\n"); } /* Call: name(); — runs the body once */ greet(); /* → Hello! */ greet(); /* → Hello! */ greet(); /* → Hello! */ /* Functions must be defined BEFORE they are called */ /* (or declared with a prototype — see Topic 3) */
⚠
Define before calling — or the compiler does not know what it is
In C, the compiler reads top to bottom. If you call a function before its definition, the compiler has never seen it and will give an "implicit declaration" warning or error. Either define the function above where it is called, or use a function prototype (Topic 3) to forward-declare it.
🌍 Printing formatted reports — reuse without repeating

Any time the same output structure appears multiple times, it belongs in a function. One definition; called wherever it is needed — the output format changes in one place.

void printSeparator() {
    printf("================================\n");
}

void printReport(char *title) {
    printSeparator();
    printf("  REPORT: %s\n", title);
    printSeparator();
}

/* Call it everywhere — the format is consistent */
printReport("Monthly Sales");
printReport("Inventory");

Topic 2

Parameters and Arguments — Passing Data In

In Progress

Run this. The same function prints different things each call — because it receives different values.

Parameters let a function receive data — arguments provide it at the call site

A parameter is a variable declared in the function's parentheses. It acts as a local variable that gets its value from the caller. When you call the function, you provide an argument — the actual value that fills the parameter. Each call can pass a different argument, making the function work on different data.

Multiple parameters are separated by commas, each with its own type declaration. C requires every parameter to have an explicit type — void add(int a, int b) is correct; void add(int a, b) is a compile error.

Parameters and Multiple Arguments
/* Parameter: type name in the definition */ void printSquare(int n) { printf("%d squared = %d\n", n, n * n); } printSquare(4); /* argument: 4 → 4 squared = 16 */ printSquare(7); /* argument: 7 → 7 squared = 49 */ /* Multiple parameters — each needs its own type */ void printSum(int a, int b) { printf("%d + %d = %d\n", a, b, a + b); } printSum(3, 5); /* a=3, b=5 → 3 + 5 = 8 */ printSum(10, 20); /* a=10, b=20 → 10 + 20 = 30 */
💡
Parameters vs Arguments — the terminology
Parameter = the variable in the function definition (int n in the header). Argument = the actual value passed at the call site (4 in printSquare(4)). In casual usage people say "parameter" for both — but the distinction matters in compiler error messages.
🌍 Formatting output with a reusable label function

Parameters make functions flexible — the same print-label function works for any key-value pair, keeping output formatting consistent across the entire program.

void printLabel(char *key, int value) {
    printf("  %-15s: %d\n", key, value);
}

printLabel("Score",     92);
printLabel("Max score", 100);
printLabel("Rank",      3);

Topic 3

Return Values — Sending Data Back

In Progress

Run this. The function computes a value and sends it back — the caller uses the result directly in printf.

return sends a value back to wherever the function was called

When a function has a non-void return type, the return statement sends a value of that type back to the caller. The entire function call expression evaluates to that returned value — so add(3, 4) evaluates to 7 and can be used anywhere a number could go.

return also exits the function immediately. Any code after a return in the same function never runs. A function with a non-void return type that does not return a value is a bug — the returned garbage value is undefined behavior.

Return Type, return Statement, Using the Value
/* Return type replaces void */ int add(int a, int b) { return a + b; /* sends the sum back */ } float average(int x, int y) { return (x + y) / 2.0; /* float division */ } int max(int a, int b) { if (a > b) return a; /* return exits immediately */ return b; /* only runs if a <= b */ } /* Using the return value */ int result = add(3, 7); /* result = 10 */ printf("%d\n", add(5, 8)); /* prints 13 */ int biggest = max(12, 9); /* biggest = 12 */
⚠
Missing return statement in a non-void function
If a function declares a return type but reaches the end without a return, the compiler may warn but still compiles the code. The returned value is garbage — whatever happened to be in that memory location. Always ensure every code path in a non-void function reaches a return statement.
🌍 Validation functions — return a status code

Functions that return int are commonly used as validators — returning 1 for pass or 0 for fail, letting the caller decide what to do with the result.

int isValidAge(int age) {
    if (age >= 0 && age <= 120) return 1;
    return 0;
}

int isEven(int n) {
    return (n % 2 == 0);    /* expression evaluates to 1 or 0 */
}

/* Caller uses the result in an if */
if (isValidAge(25)) printf("Valid age\n");
if (isEven(44))     printf("Even\n");

Topic 4

Function Scope — Local Variables and Pass-by-Value

In Progress

Run this. The function modifies its own copy of the variable — the original in the caller is unchanged.

Local variables exist only inside their function — C passes arguments by value

Every variable declared inside a function is a local variable. It is created when the function is called and destroyed when it returns. Two functions can both declare a variable named x — they are completely separate variables with no relationship. Local variables in one function cannot be accessed by any other function.

When you pass an argument to a function, C passes a copy of the value — not the original variable. Modifying the parameter inside the function changes only the local copy. The original variable in the caller is completely unaffected. This is called pass-by-value and it prevents functions from accidentally corrupting the caller's data.

Scope and Pass-by-Value
void triple(int n) { n = n * 3; /* modifies the LOCAL copy */ printf("inside: %d\n", n); } int x = 5; triple(x); /* passes a copy of x */ printf("outside: %d\n", x); /* x is STILL 5 */ /* Output: inside: 15, outside: 5 */ /* Two functions, same variable name — no conflict */ void funcA() { int count = 0; count++; } void funcB() { int count = 99; /* different variable */ } /* Local variable lifetime */ void example() { int temp = 42; /* created when example() is called */ } /* temp is destroyed here — gone after return */
💡
Local variables do NOT keep their value between calls
Each call to a function creates a fresh set of local variables starting from their initial values. A local variable that increments inside the function will start over next call. To persist a value between calls, use a static variable (covered in Chapter 14) or store the value in a variable outside the function.
🌍 Swap function — why it needs pointers (preview)

Because C passes by value, a swap function that modifies local copies does nothing to the originals. This is why Chapter 16 teaches pointers — to actually modify the caller's variables from inside a function.

void swapWrong(int a, int b) {
    int temp = a;
    a = b;
    b = temp;       /* swaps local copies only */
}

int x = 3, y = 7;
swapWrong(x, y);
printf("%d %d\n", x, y);   /* still 3 7 — unchanged */

/* Real swap requires pointers (Chapter 16):
   void swap(int *a, int *b) { ... } */

Topic 5

Recursion — A Function Calling Itself

In Progress

Run this. The function calls itself — but it stops. Trace the numbers to see why it terminates.

Recursion: a function solves a small piece, then calls itself on a simpler version

A recursive function calls itself. Every recursive function must have two components: a base case — the condition where it stops and returns directly — and a recursive case — where it does a small piece of work and calls itself with a simpler input. Without a base case, the function calls itself forever until the program crashes with a stack overflow.

Each recursive call creates a new stack frame with its own local variables. When the base case is hit, the frames "unwind" — each returning to the caller that created it. Factorial is the classic example: factorial(5) = 5 × factorial(4) = 5 × 4 × factorial(3) = ... = 5 × 4 × 3 × 2 × 1.

Recursion Template — Base Case + Recursive Case
/* Factorial: n! = n × (n-1)! */ int factorial(int n) { if (n <= 1) return 1; /* base case — stop here */ return n * factorial(n - 1); /* recursive case */ } /* factorial(4) → 4 × factorial(3) → 4 × 3 × factorial(2) → 4 × 3 × 2 × factorial(1) → 4 × 3 × 2 × 1 = 24 */ /* Countdown */ void countdown(int n) { if (n <= 0) { printf("Go!\n"); return; } /* base case */ printf("%d\n", n); countdown(n - 1); /* recursive call with n-1 */ }
⚠
Infinite recursion crashes the program — always check the base case
Every recursive call must eventually reach the base case. If the input never reaches the base case (e.g. calling factorial(-1) when the base case is n == 0), the function calls itself forever until the call stack overflows and the program crashes. Test your base case with the smallest valid input first.
🌍 Fibonacci — classic recursion that appears in nature

Fibonacci numbers model growth in nature. Recursion expresses the definition directly: each number is the sum of the two before it. The recursive code reads like the mathematical definition.

int fibonacci(int n) {
    if (n <= 1) return n;          /* base cases: fib(0)=0, fib(1)=1 */
    return fibonacci(n-1) + fibonacci(n-2);
}

for (int i = 0; i < 8; i++) {
    printf("%d ", fibonacci(i));
}
/* Output: 0 1 1 2 3 5 8 13 */

/* Note: recursive Fibonacci is beautiful but slow for large n.
   Iterative version with a loop is much faster. */
