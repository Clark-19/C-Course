Chapter 2

Data Types

Every variable in C has a type that determines how much memory it uses and what values it can hold. This chapter teaches you to choose the right type — and understand what the compiler is actually doing with your data.

8 Topics short · int · long · float · double · char · sizeof
Topic 1

Primitive Data Types Overview

✅ Complete

Compile and run this — every primitive type in one program.

C has four primitive data types that store values directly: int (whole numbers), float (decimal, ~7 digits precision), double (decimal, ~15 digits precision), and char (single character or ASCII code).

There is also void — not a variable type, but a keyword meaning "no type." It is used for functions that return nothing.

Every other type in C is built from these four primitives. Choosing the right one is a skill you will develop over time.

The Four Primitive Types
int count = 42; /* whole number — 4 bytes */ float price = 9.99; /* decimal ~7 sig digits */ double latitude = 10.3157; /* decimal ~15 sig digits */ char grade = 'A'; /* single character — 1 byte */
🌍 Mixed types in real programs

Real programs mix types constantly. A student record might use int for ID, double for GPA, and char for a grade category.

int    student_id  = 20241001;
double gpa         = 3.75;
char   honor_level = 'L';   /* L = Latin honors */
printf("ID: %d  GPA: %.2f  Level: %c\n", student_id, gpa, honor_level);

Topic 2

Integer Types — short, int, long, long long

✅ Complete

Run this — all four integer types. Note the different sizes and ranges.

C has four integer types, all storing whole numbers but with different memory sizes and ranges. short uses 2 bytes (±32,767). int uses 4 bytes (~±2 billion). long uses 4 or 8 bytes depending on platform. long long always uses 8 bytes (~±9.2 × 10¹⁸).

Use the type that fits your data — no bigger than necessary, no smaller than the value requires. For most everyday counting and indexing, int is the right choice.

Integer Type Summary
short s = 32000; /* 2 bytes — up to ±32,767 */ int i = 2000000000; /* 4 bytes — up to ~±2 billion */ long l = 2000000000L; /* 4-8 bytes — use L suffix */ long long ll = 9000000000LL; /* 8 bytes — use LL suffix */ printf("%hd %d %ld %lld\n", s, i, l, ll);
💡
Format Specifiers for Integer Types
%hd for short · %d for int · %ld for long · %lld for long long. Using the wrong specifier for the type may produce incorrect output.
🌍 Integer types in real systems

File sizes need long long. Loop counters need int. Network port numbers fit in short (0–65535). Timestamps since 1970 need long long.

short  port_number = 8080;
int    loop_count  = 0;
long long file_size  = 4294967296LL; /* 4 GB in bytes */
long long timestamp  = 1704067200LL; /* Jan 1, 2024 UTC */

Topic 3

Floating Point Types — Precision Matters

✅ Complete

Run this — float and double differ in precision. The difference shows in long decimals.

float stores decimal numbers in 4 bytes with about 6–7 significant digits. double stores in 8 bytes with about 15–17 digits. long double provides even more precision on some platforms.

The issue is floating-point representation — not all decimal numbers can be stored exactly in binary. 0.1 + 0.2 does not equal exactly 0.3 in any floating-point type. This is a fundamental property of how computers store decimals.

Prefer double for almost everything. Use float only when memory is a concern.

float vs double
float f = 3.14159265358979f; /* f suffix = float literal */ double d = 3.14159265358979; /* no suffix = double literal */ printf("float: %.10f\n", f); /* ~7 digits accurate */ printf("double: %.10f\n", d); /* ~15 digits accurate */
⚠
Common Mistake — Comparing Floats with ==
Never write if (x == 0.1) for a float or double. Floating-point numbers are approximations. 0.1 stored in binary is never exactly 0.1. Instead, check if two values are close: if (fabs(x - 0.1) < 0.0001).
🌍 double in financial and scientific code

GPS coordinates need double precision. A difference of 1 in the 8th decimal place of latitude is about 1 millimeter on the ground.

double latitude  = 10.31574800;  /* Manolo Fortich */
double longitude = 124.98765432;
double altitude  = 704.5;        /* meters above sea level */

Topic 4

char Type — Characters and ASCII Values

✅ Complete

Run this — char stores a number. The ASCII table maps numbers to characters.

A char is just a 1-byte integer. C stores 'A' as the number 65, 'B' as 66, 'a' as 97, '0' as 48. This mapping is the ASCII table — 128 standard character codes.

Because char is an integer, you can do arithmetic on it. 'A' + 1 gives 'B' (66). 'a' - 'A' gives 32 — the difference between upper and lowercase letters.

Use %c to print the character, %d to print its ASCII number.

ASCII Key Values to Know
'A' = 65 'Z' = 90 (uppercase: 65–90) 'a' = 97 'z' = 122 (lowercase: 97–122) '0' = 48 '9' = 57 (digit chars: 48–57) ' ' = 32 (space) '\n'= 10 (newline) /* Arithmetic works on chars: */ char upper = 'A'; char lower = upper + 32; /* 'A' + 32 = 'a' */ printf("%c\n", lower); /* prints: a */
🌍 char arithmetic in real code

Converting between uppercase and lowercase uses ASCII arithmetic. Checking if a character is a digit or letter uses range comparisons.

char c = 'H';
char lower = c + 32;     /* 'H' → 'h' */
int is_upper = (c >= 'A' && c <= 'Z');  /* 1 if uppercase */
int digit_val = '7' - '0';  /* converts char '7' to int 7 */

Topic 5

The sizeof() Operator

✅ Complete

Run this — sizeof() tells you exactly how many bytes each type uses on your system.

sizeof() returns the size in bytes of a type or variable at compile time. It is not a function — it is a built-in operator, like + or *. You can pass it a type name or a variable.

The result type is size_t, an unsigned integer. Use %zu to print it correctly, or cast to int with %d.

sizeof() is useful when allocating memory, writing to binary files, or verifying assumptions about platform-specific type sizes.

sizeof() Usage
sizeof(int) /* size of the int type */ sizeof(double) /* size of the double type */ sizeof(x) /* size of variable x */ /* Print with %zu (correct) or cast to int */ printf("int: %zu bytes\n", sizeof(int)); printf("int: %d bytes\n", (int)sizeof(int));
🌍 sizeof() in memory allocation

When allocating arrays dynamically, sizeof() ensures you allocate the right amount regardless of platform. This is how professional C code avoids hard-coding byte sizes.

/* Allocate space for 100 ints — works on any platform */
int *arr = malloc(100 * sizeof(int));
/* Not: malloc(100 * 4) — that hardcodes 4 bytes */

Topic 6

Signed vs Unsigned Types

✅ Complete

Run this — unsigned int can hold twice the positive range but cannot go negative.

Every integer type can be signed (default — can be negative) or unsigned (can only be 0 or positive, but twice the max value).

A signed int holds −2,147,483,648 to +2,147,483,647. An unsigned int holds 0 to 4,294,967,295 — double the positive range, because the bit used for the sign is now used for magnitude.

Use unsigned for values that are logically never negative: counts, sizes, memory addresses. Use %u to print unsigned int.

Signed vs Unsigned
int x = -500; /* signed — can be negative */ unsigned int y = 4000000000U; /* unsigned — U suffix */ signed char sc = -128; /* −128 to 127 */ unsigned char uc = 255; /* 0 to 255 */ printf("%d %u\n", x, y); printf("%d %u\n", sc, uc);
⚠
Common Mistake — Unsigned Wrap-Around
If you subtract from an unsigned and go below 0, it wraps around to a huge positive number. unsigned int x = 0; x = x - 1; gives 4,294,967,295, not −1. Never compare an unsigned value against a negative number.
🌍 unsigned in systems programming

File sizes, memory addresses, array indices, pixel values, and byte counts are all logically non-negative — use unsigned for them.

unsigned int  pixel_count = 1920 * 1080;  /* 2,073,600 */
unsigned char red   = 255;
unsigned char green = 128;
unsigned char blue  = 0;
/* RGB: no color component is ever negative */

Topic 7

Type Limits — <limits.h>

✅ Complete

Run this — limits.h gives you the exact max and min values for every integer type.

The header <limits.h> defines constants for the minimum and maximum values of all integer types. INT_MAX, INT_MIN, UINT_MAX, SHRT_MAX, LLONG_MAX — these let you write portable code that never hardcodes platform-specific values.

What happens when you exceed the maximum? Integer overflow — the value wraps around. For signed int, going past INT_MAX gives INT_MIN. This is undefined behavior in C and the source of serious bugs.

Key Constants from limits.h
#include <limits.h> INT_MAX = 2147483647 /* max signed int */ INT_MIN = -2147483648 /* min signed int */ UINT_MAX = 4294967295 /* max unsigned int */ SHRT_MAX = 32767 /* max short */ LLONG_MAX = 9223372036854775807 /* max long long */ CHAR_MAX = 127 /* max signed char */
🌍 limits.h prevents overflow bugs

Before adding two ints, production code checks if the result would overflow — a critical safety pattern in financial and embedded systems.

#include <limits.h>
int safe_add(int a, int b) {
    if (a > 0 && b > INT_MAX - a) return INT_MAX; /* overflow */
    if (a < 0 && b < INT_MIN - a) return INT_MIN; /* underflow */
    return a + b;
}

Topic 8

Practical Type Selection — Choosing the Right Type

✅ Complete

Run this — a program that stores real-world data. See which types match which data.

Type selection comes down to three questions: Does the value have a decimal part? (use double) Can it be negative? (use signed) How large can it get? (choose int vs long long).

Default rules: use int for counting and indexing, double for all math with decimals, char for single characters, unsigned only when the value is logically non-negative.

Type Selection Quick Reference
/* Data → Best type */ int student_count = 45; /* count/index */ double average_score = 87.5; /* math result */ char letter_grade = 'B'; /* single char */ long long population = 8000000000LL; /* huge num */ unsigned int bytes = 4096U; /* never negative */
🌍 Type selection in a student system

A complete student record shows all type choices in context. Each type is chosen for a reason — never arbitrarily.

int          student_id    = 20241001;  /* count       */
char         last_initial  = 'D';       /* one char    */
double       gpa           = 3.875;     /* decimal     */
unsigned int credits_earned = 120;      /* non-negative */
char         academic_stand = 'G';      /* Good standing */
